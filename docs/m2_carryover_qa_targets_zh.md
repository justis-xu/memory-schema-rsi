## 选择范围与方法

取中文 QA 的 evidence 显式包含 `conv-43 D15:3` 或 `conv-26 D17:10` 的全部题，共八道：六道类别1–4，两道 adversarial。没有按成绩或候选结果筛题。此规则不穷尽可能隐含依赖这两个细节的其他题。

对每题保留双语源窗口、两臂旧答案/成绩/15槽。比较两种**固定上下文控制**：减去两对的早版 ID，或减去两对的晚版 ID；不补槽、不重排、不重新作答。因此这里只检查直接证据是否还在，不能称为同预算的模型消融或真实删除后的系统收益。

全库 1,995 条逻辑指纹前后相同；相关在槽的四条早晚记忆正文均与当前同 ID 匹配。未证明所有其他槽位都匹配当前版本，也未把旧上下文称为当前检索结果。

## 方向不同，损失也不同

“删晚版、保早版”可能损失创造世界及情绪细节的已确认载体，但这六道 gold 都没有直接要求这两项。只用这六题分数验收，可能漏过这种事实损失。

“删早版、保晚版”则会移除 qa136 的唯一**明确把两项活动绑定陶艺暂停语境**的在槽记录；其他槽有日常阅读、绘画等材料，不能直接替代这段语境证据。模型仍可能由其他材料猜出读书画画，所以本轮不宣称一定答错。旧两臂没有选入晚版陶艺记忆，若真正改库还会引发补槽和检索变化，当前 ID 减法不能预测它们。

qa71 同样会失去在槽的伤后读书背景，但原摘要已经没保留“读的是你推荐的那本书”关系。它提醒后续来源归并应保住对象承接，而不是仅保留“阅读”这个活动标签；本轮没有把书名推断当严格来源闭合。

## 补充诊断与验收设计

机器结果留下两道**人工构造、尚未运行**的有源诊断题：

- 蒂姆在2023年10月21日谈写作，除了快乐还能做到什么？必要项是创造新世界，源 D15:3。
- 梅拉妮在2023年10月13日如何描述暂停陶艺的感受，以及如何限定？必要项为难受、但还好，源 D17:8–10。

这些题由已审源话生成，没有独立样本或隐藏测试的性质。可用于局部保全回归，不能加入官方总分、估总体收益，或声称未经选择的泛化。情绪题尤其需要补回源限定；原晚版只存难受，保留它仍不足以通过完整语义验收。

若后续开展模型 POC，应冻结当前检索候选，只改来源支持的合并文本，并保持15槽预算；明确区分原题组与上述诊断组，独立记录答案要素、主体归属、日期、被挤出的直证和调用账。一次人工合并能过诊断，也不证明自动去重能选中并正确归并候选。

## 结论、置信度与下一步优化建议

高置信：八题选择、六题 gold 范围、旧在槽 ID/文本、离线减法，以及 qa136 的直接载体位置。中高置信人工判断：原题没有直接测这两个独有子句；qa136 移除早版会失去明确语境证据。未知：真实归并后检索补槽、模型答案和整体净收益。

优化顺序据此调整：先以 qa136 检查实际原题的直证保护，再以两个有源诊断检查原题分数看不见的细节与限定语，最后在独立中文问题上估净收益。RSI 接受门控至少需要原题表现与事实保全两类证据；仅优化规范 ID 数或局部 exact 会留下评测盲区。当前阶段不证明归并有效或无害，也不意味着整体复盘完成。
