## 背景与使命

我在研究 Graph、Jev、RSI 如何改善记忆效果。目前实验效果不理想，但方向值得继续验证。核心任务是深入复盘历史数据，理解哪些环节真正有效、哪些结论受数据或评测方式影响，并持续发现可验证的优化方向。项目的一切都可以质疑，结论必须回到代码与真实证据。

5. 旧归档无法识别反事实时，记录缺失日志。新增运行前写明问题、样本、对照、最大调用量和反伤检查；优先小规模中文 POC。
