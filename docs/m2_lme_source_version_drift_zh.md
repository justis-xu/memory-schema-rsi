## 研究含义与边界

已审的五题、23 处原话及其支持强度标签，在本次读取快照下仍有逐字来源；因此**没有证据要撤回这些特定源话判断**。但答案来源批次有 5 个已变，若用当前数据重跑 Mem0 提取，模型输入就不完全等于旧来源账，输出差异不能只归因于提示词或模型。只核 23 处引用也不足以证明五题的其他上下文语义完全相同，更不足以推断全 470 题的变化范围。

**结论与置信度：** 对本快照 SHA、232 批逐项对账、37 个消息变更批次、10 个答案来源 turn 差异和 23/23 原话匹配为高；对未保存旧全文的 32 批内容与全库影响未知。

**下一步优化建议：** 后续中文提取或 Graph/Jev/RSI 同条件试验必须固定实际输入文件 SHA，并保留样本级批次指纹、运行/重试 ID、输出原文和来源支持判断。若沿用五题人工 oracle，只把 23 处已匹配原话作为可复用部分；其他上下文先查版本差异。对于正在变化的忽略数据文件，不在两次运行间默认它稳定。
