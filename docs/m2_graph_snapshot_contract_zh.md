# 图快照准入与切换：离线契约验收

## 问题与数据范围

承接部分提取和旧图残留审计：怎样同时允许合法空结构、拒绝失败伪空、撤回旧关系，并保住可用旧版本？本阶段不是继续统计历史错误率，而是验证候选优化规则能否满足已发现的控制流程要求。

范围：13 个合成中文控制场景、3 条初始 Memory 与3条更新 Memory。使用真实 S1 normalize/build_s1 和融合 GraphRetriever；存储与版本注册表为内存对象。零模型调用、零真实库写入，没有生产接入或答题实验。

产物：`scripts/m2_validate_graph_snapshot_contract.py`、`results/analysis/m2_graph_snapshot_contract_20260928.json`。

## 候选规则

1. 输入必须是同用户、无重复 ID 的完整源清单；响应 ID 集合须与其完全相同。每条提取保存成功状态、输入指纹和提取配置指纹。
2. 在 normalize 之前核四类字段均为列表，条目具备最低必填字段。只把完整且结构有效的空列表判为合法空；漏 ID、错误类型、无名称实体等不允许经清洗伪装空结果。
3. 源版本指纹含排序后的 ID、正文、metadata 和提示/模型/schema/compiler 版本。提取正文指纹另含完整 MemoryRecord。清单枚举顺序不改变版本，日期或模型变化会改变版本。
4. 在独立内存图构建完整版本，成功后才切换 active 指针。失败保留旧物理产物，不发布半图。
5. 读取时比较当前完整源清单与 active 的版本指纹。不匹配则图候选为空，退回向量路径；源未改变的刷新失败仍可继续读取旧匹配图。

本轮是完整快照方案的原型。失败时不发布整批，较逐 Memory 部分更新更保守；是否值得为少量失败关闭该用户整图，需要后续曝光和收益证据。不能把这一取舍直接当作最优策略。

## 结果

13 个场景的预期断言均通过：3个发布成功、10个拒绝或发布前失败。

|场景|结果及控制|
|---|---|
|删除旧ID、同ID改内容/实体|新版本无 deleted，旧话题不再拉 changed；新话题仍能拉 replacement|
|单条合法空|该条 Memory 保留，所有旧出边撤回|
|全部合法空|发布仅含 Memory 的图，无派生边|
|源已变、当前提取失败|旧对象保留，版本不匹配，读取退回向量|
|漏响应ID|拒绝整批，旧对象保留|
|实体字段错误类型|拒绝，不能视为合法空|
|实体只有type没有name|拒绝，不能视为合法空|
|同ID复用旧正文缓存|输入指纹不符，拒绝|
|改提示后复用旧提取|配置指纹不符，拒绝|
|源清单重复ID|拒绝|
|源清单混入别的用户|拒绝|
|构建后切换前注入异常|旧指针保留，没有半成品替换|
|同源版本刷新失败|保留且继续读取原有效图，不误关闭匹配旧版本|

另有清单顺序不敏感、日期敏感、模型版本敏感三项指纹断言。以上证明的是候选契约在合成控制上的行为，不是抽取准确率、真实图事务或答题收益。

## 与现有代码的差异

- 当前 extractor 没有这些成功状态和指纹，不能从已有 normalized 空缓存补推成功；旧缓存应标 unknown，不能自动升级为已验证结果。
- 全部合法空是原型的显式 Memory-only 分支。当前 build_s1 的全空拒绝仍存在，未修改；生产接入需要在明确逐ID成功证明之后才放行合法全空，不能删除防线后无条件放行。
- 独立内存图自然撤回旧边。本轮没有实现 HugeGraph 的版本命名空间、查询选择、原子指针或旧版本回收；不能在共用服务上直接照搬全图 reset。
- 完整清单是必要前提。代码复核发现 Mem0Backend.get_all_memories 使用 `_GET_ALL_LIMIT` 的 top_k 参数，ChromaDirectBackend 则直接按用户取记录；实际清单是否完整、库是否在构建期间变化仍需核查。不能用向量 topK 或“get_all”方法名作为完整性证明。
- 结构验收只核最低必填字段，未完成枚举语义、源turn真实性、事实主体和支持强度检验。此版本规则不能补出Memory里原本遗漏的吉娜赞同关系，也不能把内特语境回答升级为明确唯一最爱。

## 结论、置信度与下一步

**高置信度，离线控制范围：** 可以同时保护失败旧产物与拒绝过期读取；“保留旧图”不等于“允许旧图继续参加当前查询”。合法空与失败分离后，可撤回旧关系而不把失败当删除依据。

**未知：** 真实服务切换能力、缓存成本、关闭过期图的实际曝光，以及中文Graph/Jev答题净收益。13个控制场景不可外推错误率或收益。

下一步先从真实中文源清单与当前接口核完整性、分页/上限和并发版本变化，明确最低接入点，再选择一个可验证的运行路径修复。后续中文配对试验须固定源版本、提取版本和完整候选，分别测独有事实增益与直证反伤；原型通过不能替代这一步。
