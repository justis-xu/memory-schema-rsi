## 对研究使用的含义

- **历史复盘的原始产物可用。** 归档在 HF 清单里的逐题结果、中文运行和 RSI 输出均通过内容哈希，足以继续分析旧运行的候选、答案、评分和相互配对。清单核验只覆盖本机缓存的这个版本，不证明 HF 远端此刻没有新提交。
- **英中基准已在本机。** LoCoMo 英中两份、LongMemEval-S 英中两份均存在；前一轮结构审计确认 LoCoMo 各 1,986 题，中文 LongMemEval-S 为 470/英文 500 题。那是数据内容和结构的独立核查；四份基准不全属于本轮 HF 结果清单。本轮只补文件存在与大小，未重新审翻译语义。
- **中文 LongMemEval 的结果仍缺。** 已到位的是基准数据，不是完整中文评测。历史 LongMemEval 逐题结果仍只见英文小批量试跑，不能拿来判断中文 Graph/Jev/RSI 效果。当前配置的 LongMemEval 路径也指向英文文件。
- **当前中文图实验须另建版本对照。** HF 归档结果可做历史机制分析；当前 Chroma 字节已与清单不同，活图和缓存也未与当前中文 ID 全量对齐。任何新图或 Jev 实验都要同时记录数据文件、当前逻辑库指纹、图节点及候选集版本。

这次检查解决的是“历史文件有没有完整落地”及“哪些是冻结归档”的问题；它没有测量功能收益，也没有给当前工作库贴上历史运行版本标签。
