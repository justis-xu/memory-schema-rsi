# 六条“只见图候选”的记忆：当前缺库不等于历史无源

> 2026-09-26。只读八份中文主运行、当前 Chroma SQLite、Mem0 history、图缓存和中文 LoCoMo 源 turn。脚本与逐 ID 机器结果：`scripts/m2_audit_graph_only_memory_ids.py`、`results/analysis/m2_graph_only_memory_ids_20260926.json`。未调用模型，SQLite 以只读方式打开。

## 问题与结果

前轮发现八臂图候选并集中有 6 个 ID，从未出现在八臂向量检索并集中。它们是否意味着图在使用“向量库里不存在的脏记忆”？逐 ID 核对后，结论要更窄：

| 核对层 | 结果 |
| --- | ---: |
| 图独见 ID | 6 |
| 五份融合图运行中的候选出现 | 679 次 |
| 最终上下文入选 | 49 次 |
| 当前向量库中同 ID 同正文 | 5 条 |
| 当前向量库中已不存在 | 1 条 |

五条仍在当前 Chroma 中的记忆均带 `session_id=session_11`、`session_date=2023-07-08`（`conv-44`），正文与旧图候选完全相同；它们只是没有进入这些归档的向量**检索结果**。不能把“没被向量召回”误写成“历史向量库从未有过”。

第六条 `bae6d454-...`（`conv-48` 的乔琳压力与自我照顾）当前 Chroma 已无此 ID，但 Mem0 history 有 `ADD`（2026-09-25 03:41 UTC）和 `DELETE`（2026-09-26 00:20 UTC）两条事件；该记忆在 2026-09-25 的中文图评测中进入最终上下文 33 次。中文源会话 `session_8` 日期为 2023-03-02，乔琳在 `D8:14` 自述需要关注压力和心理健康，在 `D8:16` 自述考试、截止日期和待办清单让她不堪重负。它的核心事实有源；后来被删除的原因，历史事件表未提供。现有证据不支持把它标成“评测时图幻造的记忆”，也不证明它在这 33 次都与题目相关。

此前图上下文审计中 **2,042 次图入选有 2,034 次能从归档向量检索恢复日期**。剩余 8 次现在定位到两个 ID：上述乔琳记忆 6 次，`conv-44` 一条公园野餐记忆 2 次。后者目前在向量库有日期；前者可人工回源到 `D8:14/16` 的会话日期。原来“归档向量检索中只能恢复 2,034 次”的统计仍正确；本轮扩展的是这 8 次的**来源解释**，不是声称所有图日期能从当时的在线向量接口自动恢复。会话日期也只是“提及时间”，不能直接当事件发生时间。

## 结论、置信度、下一步优化建议

**结论：** 六条图独见记忆中五条仍在当前向量库，一条在历史评测后被删除且核心内容有中文源 turn。图独见体现了图扩展与向量排序的不同覆盖面；不能据此判图缓存陈旧或新证据有效。49 次入选里有 33 次来自后删的同一条记忆，值得按题核其证据贡献和挤出项。

**置信度：** ID、正文、当前库状态、ADD/DELETE 事件和两个源 turn 为高；历史删除原因、当时完整库状态以及入选对答案的净影响未知。当前数据库状态晚于评测，源 turn 核对只覆盖后删记忆的核心事实，不等于验证所有措辞或日期换算。

**下一步优化建议：** 先从 49 次入选里选与金标源事实有明确关系的中文题，逐题对比图候选独有事实、被挤出的旧事实和两臂答案；优先检查那 33 次乔琳记忆的真相关性。未来运行把图候选的原始记忆 `session_id/session_date` 与来源 turn 一起透传，并为向量库删除/图索引失效留下同一版本的事件记录。
