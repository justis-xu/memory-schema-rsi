## 来源强度修正：保留问答限定，不制造排名

上阶段将 `D27:22–23` 记为“问答支持的最爱游戏”。这里进一步限定：内特没有逐字说“我的最爱是异度神剑”，他用正在玩的游戏回答最爱提问。它支持**在最爱游戏提问语境下介绍了异度神剑**，强度弱于本人明确最爱排名。金标有对话语用支持，不能因此宣布其错误，但也不能将关系修复写成“永久唯一最爱”。

建议的有源表达是：“2022年11月7日，内特被问到最爱的游戏时介绍了最近正在玩的《异度神剑》，称它很棒并强烈推荐。”源轮同时保留 `D27:22` 与 `D27:23`。这只是人工来源表达例子，未写入Memory，也不是自动提取或答题收益。

吉娜 `D1:8–9` 的“我也是”明确承接对方最爱陈述；内特这里是提问后用近期游玩回应。两者都需要邻轮，但支持方式/强度不同。英文atomic在吉娜保留偏好、在内特只保留正在玩，说明不能把“原子化”这个名称当作所有关系限定都被保存的保证。

## 结论、置信度、下一步优化建议

高置信：原话、可见标题正文、版本ID和history时间字段。来源谓词强度为中等置信的人工语用判断；缺真实提取请求/响应，不能归因于具体模型、提示词或保存阶段。现有旧/当前/其他namespace/英文缓存都未显式保留这段提问语境，但不是受控重跑，不能给组件因果结论、总体漏提率或当前Graph收益。
