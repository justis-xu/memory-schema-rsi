# 无图独得 exact 的固定 12 题：必要事实是否被图挤出（2026-09-28）

## 问题、范围和方法

正向翻分样本已有大量“必要事实早已在无图槽里”的题，本轮对称检查反向翻分：图进最终上下文后，是否挤掉唯一必要事实，还是证据保留但回答或裁判发生变化？

使用同一对历史中文无图/融合图运行及 precision 重判。排除 adversarial 和此前五道已审机制题，要求无图 exact、图非 exact、图候选实际进入最终 15 条、两臂最终 ID 集合不同，共 45 题。按 `SHA256("m2_graph_harm_sample_20260928|" + case_id)` 排序取前 12，不看题面选样、不替换。源话、英中邻窗、两臂有序 15 条、进出记忆和裁判原文在 `results/analysis/m2_graph_negative_fact_loss_sample_20260928.json`；人工标签及额外回源在同名前缀的 `labels` 文件；复算脚本为 `scripts/m2_sample_graph_negative_fact_loss.py`。

只读历史文件，零新增模型调用，不写记忆库。对照为历史无图臂，反伤核查逐题核“被挤出项是否含图臂不再拥有的必要事实”，并回查 QA evidence 及邻轮。两次独立运行仍不构成冻结条件反事实。

## 结论、置信度与优化建议

高置信的是固定样本ID、实际有序槽、进出项和裁判原文。是否核心保留及必要事实独有是人工判断，置信度中等；事件同一性、州名推断与 Graph 因果影响仍未知。此轮没有改历史成绩或数据集。

1. 中文裁判规则先明确近似时间、额外有源信息、核心名词/主观修饰语和否定限定的口径。两臂同样包含的内容不能一边允许、一边拒绝；保留旧分与新核查记录，避免用翻分直接调图参数。
2. 把 `qa152` 的“运动种类漏答”、`qa61` 的“计划/完成/不同项目混合”、`qa90` 的“喜欢/读过/最爱混合”列为答题证据使用病例。冻结同一有序上下文后才能辨别生成稳定性，再引入等槽图替换和反伤控制。
3. `qa48` 的来源只给地名，不给州名；后续明确是否允许外部知识以及推断应如何标注，避免把谨慎拒答自动算作检索坏了。
4. 下一步继续寻找**当前同版无图缺失、图路由带入且有原始来源的必要关系**，同时记录每条图候选的新增事实、共享事实、被挤出事实和源 turn。当前这12题不支持“必要事实挤出是主要失分机制”，也不能排除排序、干扰、生成与评分共同作用。
