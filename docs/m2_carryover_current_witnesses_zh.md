## 方法与范围

只读当前 SQLite，逐 ID/正文比对历史两端；人工确认六项细节的当前内容载体，并保存其 owner 完整记忆快照供复核。离线控制仅从“两个 ID 都存在且正文相同”的八对中移除较晚 ID，计算**已确认载体**剩余情况。不做实际删除，不调用模型。库前后 1,995 条 ID/正文/owner/场次逻辑指纹一致。

人工载体列表不是自动语义搜索，也不证明没有其他同义记录。保留旧事实标签，仅补当前版本证据和限定；“失去全部已确认载体”不能直接写成“全库一定丢失事实”或“答案一定退化”。

## 旧标签的两处颗粒度需要收窄

1. 旧 inventory 将“写作给他快乐，并让他创造全新世界”作为一项，并标 `in_older_memory=False`。实际上较早摘要已写“写作带给他巨大快乐”；**较晚独有的是创造全新世界这个子句**。整项布尔覆盖标签不能精确表达部分保留。
2. “暂停陶艺让她难受，但她说自己还好”被标为晚版有；当前及旧晚版只写难受，未写“但我还好”。源 D17:10 明确同时说这两部分。保住晚版仍没有保住完整限定语，不能用 `in_later_memory=True` 宣称完整源语义已保留。

本轮没有重算并替换旧 38 项粒度；旧总数是旧人工划分的数量，其接受原型证明的是标签/来源指针契约，不能当成每个复合主张都被摘要完整覆盖。若用它做自动归并回归，应把复合项拆为子句，并区分 full/partial/absent，而不是复制旧布尔标签。

情绪限定也不能脱离对象泛化：“她还好”是在暂停陶艺的问答中的自我报告，不应推广为一般健康状态。同样，“难受”与“还好”可以共存，不必判成知识更新冲突。

## 新版本仍有同行者身份具体化

当前约翰 session11 记忆 509b61c0…写“和朋友”公路旅行。读完整中文 session11，D11:3/5 只说“我们”；D11:4 玛丽亚问“你们那次公路旅行去了哪里”，也没有指定同行者。图片 query/caption 描述风景，没有提供朋友身份。

此前旧两版分别补“家人”“玛丽亚”，本轮的新中文摘要改为“朋友”，但相同的来源缺口仍在。不能因新 ID、中文重提取、或换成更常见的身份，就当作来源问题已修复。这里是对**所挂源场次**缺支持的判断，未证明其他会话绝无这次旅行的同行者信息；不修改当前记录。

## 结论、置信度与下一步

高置信：八对 ID/正文仍对应、四对旧 ID 消失、列出的当前载体及离线控制的 ID 进出、库未变。人工内容覆盖与同行者支持判断为中高置信，受颗粒度和所查源范围限制。自动语义去重能力、真实检索改善、中文答案净收益均未知。

优化建议：

1. 归并操作使用当前源版本及事实级载体清单；删除前必须确认每个有源子句在保留正文中完整覆盖，限定语单独检查。对不确定覆盖保留原记录，避免将布尔标签当自动蕴含证据。
2. 先修事实标注颗粒度，再用两个仍有载体损失风险的病例验证“整条删除”与“按源补回独有子句”之差；真实模型试验需要冻结当前候选并另行公布调用预算、对照和反伤。
3. 新提取回归加入当前“朋友”身份例，允许保留“约翰参加公路旅行”，拒绝由未解析的“我们”补具体同行者。这比只检查旧家人/玛丽亚两个词更能检验来源能力。
4. Graph/RSI 的局部更新不能仅看规范 ID 数变少：应同时看有源子句、限定语和时间归属是否保持，再记录检索槽释放与最终答案。当前结果未证明去重带来净收益。
