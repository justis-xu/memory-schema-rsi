## 结论、置信度、下一步优化建议

**结论：** 来源日被写成事件日会把无源精确日期带入答题上下文，且至少有定向答案复述了与原话冲突的事故日。219 是暴露次数，32 是字面提及次数；两者都不是因果伤害计数。`qa74` 的混合表述说明仅靠字符串扫描还会把正确的谈话锚误判成错误断言。

**置信度：** ID 入槽、运行文件 SHA、219/28/32/14 及引用答案原文为高；逐题“错误日期断言”人工判断为中高。当前没有删除或改正该条后的同条件答题对照，不能估收益或反伤，也不能把这 28 题当独立试验样本。

**下一步优化建议：** 先固定 `qa74` 的时间问法、`qa144` 的多余日期限定、`qa133` 的无关故事、`qa191` 的主体纠正四类病例，构造**只改事故日期／来源标记**且保护其余独有事实的候选对照；同槽位重复答题并记录每次挤出与答案差异。若原问金标或源时间锚含歧义，先回源裁决，再评是否有净收益。
