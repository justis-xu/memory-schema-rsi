# 中文偏好题的主体与来源说话人：筛查不能替代关系核查（2026-09-28）

## 问题、范围与方法

上一阶段 `conv-43_qa166` 的金标指定证据属于另一人物。本轮检查这个线索是否还有同类病例，并检验“题目人物不同于证据speaker”是否能直接判错。

从本地HF LoCoMo中文1986 QA中取非adversarial、题面含 `最喜欢/最爱/喜欢什么/喜欢哪些` 的题，共51道；要求题面逐字出现且只出现一个真实会话speaker姓名，得到46道，5道不满足直接姓名规则排除。逐一解析evidence：1道有缺失ID，不将不完整列表视作“全是他人”；其余按“所有ID有效且所有证据speaker都不是题目人物”标记，得到2道。这里只筛该明确子集，不覆盖别名、隐含主体、其他偏好措辞，也不将未标记题宣布正确。

脚本 `scripts/m2_screen_preference_source_subject.py` 保存46道完整筛查表、两道标记题的英中源邻窗、无图/图历史答案与有序15槽和原始precision分；输入SHA可复核。机器文件为 `results/analysis/m2_preference_source_subject_screen_20260928.json`，人工判读在 `results/analysis/m2_preference_source_subject_labels_20260928.json`。零新增模型调用，未改数据集、记忆库或历史成绩。反伤核查是防止以speaker不同为由误删跨轮有源关系。

## 缺失指针与覆盖限制

46题中唯一不完整列表是已审 `conv-42_qa88`，evidence含无效 `D` 及有效 `D1:18/20`。本轮保留异常，不自动修复、不重复其已有图像字段审计。44道未触发speaker标记的题没有在本轮逐题语义裁决，可能仍有关系类型、偏好强度、图片字段或金标问题。因此不能用1/46推全库错误率，不能把2个标记等同2个错误，也不能以该筛查声明HF语义全审完。

## 结论、置信度与下一步

高置信：51→46→2的字面规则结果、speaker、原话与两臂归档可复算。qa166指定来源主体错配为高置信；qa111的片名指代关系为中高置信的上下文推断，非戴夫亲口命名。自动来源验证能力和修正评测后的总体分数仍未知。

优化建议：

1. 来源验收核对**事实主体**而非仅比较speaker。对自述、转述、提问限定、对方补名称分别记录；给每条关系保留必要邻轮的源ID与支持等级。
2. 评测清洁集先排除qa166这类指定来源错配，但保留旧分和明确的隔离记录；qa111保留上下文支持标签。未经人工回源不自动改题或gold，也不将同speaker题当已通过。
3. 在后续Graph/Jev/RSI门控中同时检查人物、谓词、媒介类型和偏好强度。图应证明有源关系或关联补齐，不能通过命中错人gold获得接受。
4. 下一阶段继续查看尚未核查的偏好关系或来源限定损失，再选有源、当前同版无图缺失的关系做受控验证。当前无需对这两个已识别病例追加盲目模型调用。
