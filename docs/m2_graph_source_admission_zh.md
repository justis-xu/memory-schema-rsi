# 当前源候选准入接口：实现与定向验证

## 问题、范围与实现位置

承接真实迁移审计，本阶段将源ID/正文准入规则实现成可独立调用的运行接口，避免后续实验把向量topK当完整源清单，或继续接纳已删除ID。

实现：`src/schema_rsi/evaluation/graph_admission.py`。验证：`scripts/m2_verify_graph_source_admission.py`；机器记录：`results/analysis/m2_graph_source_admission_20260928.json`。

数据是只读当前conv-30全部102条Memory，以及合成候选/过期/版本控制；另将真实GraphBuilder/GraphRetriever记录器回放的候选送入新接口。零模型调用、零真实图写入，前后源逻辑指纹一致。**目前没有接入EvaluationPipeline：现有评测行为未改变，不称线上问题已修复。**

## 接口行为

`SourceSnapshot.from_records` 冻结同用户唯一ID清单、正文和metadata，显式记录完整性状态、revision、有效性参考日期；指纹包括完整冻结记录和日期口径。冻结后调用者修改原MemoryRecord不会改快照。完整性和revision来自调用者提供的证据，接口本身不会凭记录数量证明完整。

`admit_graph_candidates` 保持候选顺序、via/support，不重排，不查库；返回准入候选及逐条原因trace。它执行：

- 不完整清单、请求owner不符、显式图源指纹不符：拒绝整个候选池。
- 候选owner缺失或不符、无当前ID、同ID正文变化、空正文、过期、无效过期日期：拒绝该候选。
- 重复候选只保留首个成功准入者；失败候选不占去重名额。
- 同owner/ID/正文通过后，从冻结源恢复session_id/session_date。日期缺失仍保持缺失，不凭图里的旧日期补造。
- 没有图源manifest时标`relationship_provenance=unverified`；有相等指纹时标`manifest_claim_only`，不把字符串相等当作提取语义或边构建证明。

同ID旧正文不直接换成新正文继续参与召回，而是拒绝并要求关系重建；仅替换正文会掩盖旧关系来源。但同ID新正文已写图、旧边没删的情况仍无法靠此身份接口识别。

过期采用冻结参考日期，expiration_date早于该日才过期，同日有效；无效日期拒绝。Mem0目前对无效expiration_date视为未过期，这里是显式更严格的候选策略，未改Mem0策略，也没有在当前库观测到过期字段。

## 16项定向验证

|控制|观测|
|---|---|
|真实当前候选在一条向量池外|仍通过；完整源是102条，非topK；恢复真实场次/日期，保留via/support|
|删除ID|拒绝absent_current_id|
|同ID旧正文|拒绝，要求重建关系|
|异用户候选|拒绝|
|未知候选owner|拒绝|
|不完整topK源|全部拒绝|
|源快照与请求owner不符|全部拒绝|
|重复池条目|保留首个，通过/拒绝逐条留痕|
|显式旧图源指纹|全部拒绝|
|相等manifest|允许身份一致候选，但只标声明匹配|
|原输入对象后续被修改|冻结快照和准入正文不变|
|参考日期前一天过期|拒绝|
|参考日期当天过期|通过|
|无效过期日期|拒绝|
|真实检索回放的deleted候选|拒绝|
|真实检索回放的新正文/旧关系候选|身份通过，但关系仍标未验证|

每项还核输入候选不被修改。执行脚本的断言全部通过，代码编译检查通过；未运行pytest、模型、服务集成或答题对照。

## 结论、置信度与边界

**高置信度，接口与定向控制：** 已有可复用、可留痕的当前源身份防线，能够拒绝删除/旧正文且保护向量池外合法候选。其行为不依赖模型判定。

**仍未解决：** 完整源读取证明、过期字段从实际后端透传、快照读取后并发变化、图关系版本证据、邻接限额已被旧节点占用后的补拉，以及真实答案收益。身份门控在检索之后执行，不能追回已在图服务邻接limit阶段被截断的合法候选。

本接口是候选准入组件，不是完整版本图修复。前阶段独立快照契约包含提取配置/schema/compiler；本组件的source指纹只描述源清单与日期，不证明完整提取配置一致。不能直接把它冒充完整图版本manifest。

## 下一步优化建议

1. 把来源快照证据传入融合、旁路与Jev扩拉三条入口，保存每次准入trace；接入前解决实际完整读取证明，不能直接将目前get_all的一次返回声明complete。
2. 当前库单用户远低于限额，可先用只读源快照做固定源实验；实验仍需保存读取时刻、源revision和两臂候选。不依赖未核的线上图缓存。
3. 构图应保存逐ID处理状态及关系版本，完成后发布可核manifest；同正文旧边与旧节点占邻接限额要在构图/检索前端修复。
4. 本轮完成接口行为验证后，不继续堆叠同类合成控制。回到实际当前图的版本和候选曝光，再挑有源独有关系题做中文配对检索/答题试验；提取或准入正确不能替代净收益。
