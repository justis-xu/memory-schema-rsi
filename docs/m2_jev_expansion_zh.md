# Jev 扩拉后，最终选入的是新线索还是旧候选？

> 2026-09-26；只复算归档，零新增模型调用。脚本：`scripts/m2_audit_jev_expansion.py`；机器结果：`results/analysis/m2_jev_expansion_20260926.json`。这里的“新”严格指 **ID 不在同夜无 Jev 臂的同题向量＋图候选池**，不等于新增事实，也不等于 Jev 首判时没有该候选。

## 对照与可识别边界

中文 2026-09-25 的无 Jev 融合图臂与 decider、laya 两个 Jev 臂，按共同 `case_id` 和严格重判配对，只纳入 single-hop、multi-hop、temporal、open-domain。Jev 归档只保存扩拉后的完整候选池、最终答题上下文和首判／二判分数；**没有首判的有序 15 条上下文及完整候选 ID**。同夜无 Jev 臂在未扩拉题里图候选 ID 大多相同，因而可作近似参照，但两臂是独立运行，不能把它当真正的扩拉前快照。分组是扩拉后的结果，组间翻分也不能当干预效应。

本次逐题用 `answer_context_ids` 重建最终入选，避免使用扩拉后已过期的 `graph_context_ids`。日期、内容与顺序也用于判定两臂上下文是否完全相同。Jev 首判有分数的共同 J 题是 decider 1,539 道、laya 1,537 道；laya 另有 2 道没有评分记录，以下排除。

decider 扩拉的 732 题里，**418 题（57.1%）**最终没有选入对照池外 ID；其中 384 题连有序 ID、内容和日期都与对照相同。laya 对应 **90/166（54.2%）**，其中 78 题完全相同。其余 34、12 题主要是从对照旧候选池内重新选入或排序。代码每次扩拉都会重新取图候选、重排、二判；它并不先检查新候选是否真正进入最终 15 槽。

扩拉并非没有产生候选：相对无 Jev 对照，decider 扩拉组有 **13,500 次图候选 ID 在对照图池之外出现**，laya 为 **3,041 次**；但只有上述 447、116 次池外 ID 进入最终上下文。数字是逐题出现次数，记忆 ID 会跨题重复。扩拉还分别有 2,512、551 次对照图候选 ID 不在最终扩拉图池里。源代码中的扩拉是**重新取候选并替换原图池**，没有保证旧图候选单调保留；跨运行候选漂移也混在这些差异内。未扩拉组也有 21、49 次池外 ID 入选，主要来自向量检索差异（17、45 次），说明不能把所有池外 ID 都记到 Jev 扩拉头上。

扩拉后选入池外 ID 的题，decider 有 269/314、laya 有 67/76 道的向量候选 ID 顺序仍与对照相同；池外入选 ID 绝大多数来自图臂（429/447、112/116）。这增强了“扩拉改变图候选选择”的解释，但仍不是同一次运行的首判反事实。相对对照最终上下文，这两组分别有 451、117 次旧 ID 被挤出；不能只数新增而不数挤出。

## 新 ID 与严格翻分是否指向新事实？

选入池外 ID 的组，decider 是 **11 赢、22 输，净 −11**；laya 是 **3 赢、2 输，净 +1**。未选入池外 ID 的扩拉组，decider 是 21 赢、26 输，laya 是 3 赢、8 输。即使在旧池且上下文完全相同的扩拉题里，decider 仍有 **20 赢、22 输**，laya 有 **2 赢、7 输**；这正是现有生成／判分波动不能忽略的参照。二判分数仍小于 0.4 的题，在“新 ID 入选”组是 decider 285/314、laya 47/76；在“旧池”组是 416/418、83/90。评分变化也没有稳定地证明扩拉补齐了证据。

我逐一读了 **14 道“池外 ID 入选且 Jev 独得”**题的新入选记忆、两臂答案及严格裁判理由（机器结果保留全文）。**没有一题能仅凭新入选记忆明确指出：它独有地提供了对照答案缺少且金标要求的事实。** 这是一轮人工定向核查，不是对所有 390 道新 ID 入选题的语义穷尽；新记忆也可能通过改变上下文顺序间接影响答法。

几个能看清边界的例子：

- `conv-42_qa118`：两臂都答“椰奶糖霜”，新增记忆谈内特教别人做无乳甜品。对照裁判认为“椰奶”与金标“椰子奶油”不同，Jev 裁判却认为相同；这次翻分主要暴露**同一关键措辞的判分不一致**。
- `conv-49_qa49`：对照只提埃文的儿子受伤，Jev 补充埃文自己膝伤，属于真实答案内容差异；但唯一池外入选记忆讲的是**萨姆**健康受影响，并没有提供埃文膝伤。不能把该补全归因于新增记忆。
- `conv-49_qa72`：对照答案已经明确写“徒步/爬山”，却因并列措辞被判 partial；Jev 答“徒步”被判 exact。新增记忆提到萨姆以前爱徒步，可作相关背景，但“徒步”不是对照答案缺失的事实。
- `conv-49_qa1`（laya）：两臂都列出旧、新普锐斯，也都混入膝盖／儿子受伤；对照因此判 partial，Jev 却将额外元素视为无害而判 exact。新增记忆恰好是儿子踢球受伤，不能解释为补足两辆车的证据。

这些例子支持先检查**新证据是否独有、是否回答当前问题**，再用翻分判断价值。14 道中至少有明确的裁判口径冲突，单次 exact 翻转不能替代逐题证据审计。

## 结论、置信度、下一步

**结论：** 这批中文 Jev 扩拉更多是在扩大候选并重新竞争 15 个槽位，过半扩拉题最终没有选入近似首判池外的 ID；在选入池外 ID 的题中，也未看到可由现有日志明确证明的“新增必要事实带来净收益”。这不否定证据充分性门控本身，只说明当前实现与日志没有建立“触发 → 新证据 → 答案改善”的可验证链条。

**置信度：** 对归档入选数、候选进出账和翻分为高；对“真实首判新增多少线索”为低，因为首判池没有保存且对照跨运行；对 14 道定向案例的事实判断为中，不外推为全体比例。所有结果仍来自旧混合语言记忆库，不能作为当前纯中文库效果。

**下一步优化建议：**

1. 在首判前保存有序 15 条 ID、完整内容哈希、日期、来源和图池 ID；扩拉后同样保存。若上下文完全一致，跳过无信息量的二判，直接用首判上下文作答，并记录节省的调用数。
2. 对扩拉新候选先做“当前问题所需事实＋可信源 turn＋是否已在旧上下文”的检查，只有独有且可核的候选才替换旧证据；旧图池应保留或明确记录淘汰原因。
3. 用固定中文小题集做同一次候选池的重排消融：同一向量候选、同一答题预算，只切换新图候选入选；先观察证据覆盖与挤出，再用重复作答及统一裁判检查净收益。模型调用须单独限定上限。
4. 先审查这 14 道及同上下文翻分题的严格判分口径，尤其同义词、近似日期和额外细节；否则扩拉策略会学习判分噪声。
