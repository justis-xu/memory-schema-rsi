# 中文记忆实验的综合判断：先定位事实断点，再决定是否加图、Jev 或 RSI

> **更新入口：** 2026-09-29 的当前决策版见 [Graph、Jev、RSI 中文记忆复盘](m2_integrated_retrospective_20260929_zh.md)。本文保留 2026-09-26 当时的证据和判断；后续真实隔离写入、跨基准角色语义、当前缓存/图就绪及缺题界限以新版为准。

> 2026-09-26。综合已归档的中文 LoCoMo、HF 数据覆盖、来源审计、Graph/Jev/RSI 专项和小型 POC。本文是**决策索引**，不是一次新评测；未调用模型，也未把旧运行重算为当前纯中文库成绩。逐题数值和脚本请沿文末证据索引查原专项。

## 现在能够作出的判断

1. **中文 LoCoMo 适合继续逐题分析，但历史小幅净分不能当作稳定功能收益。** 八份主运行覆盖全部 1,986 题的并集，交集为 1,941 题；一对无图/融合图 J 类配对显示图净增 17 道 exact，但按对话重抽样的 95% 区间为 −0.80 至 +3.01 个百分点。图入选 2,042 次，同时挤出 2,084 次原有记忆；482 道最终上下文内容和日期完全相同的题，仍有 59 道 exact 翻转。同配置重跑亦有大量逐题翻分。现有设计能指出候选替换与失分病例，不能从一次净增估计图的稳定净效应。图仍可能对特定事实有用，关键是找到**源支持、原上下文没有、入槽后可答**的病例。
2. **瓶颈不是单一的“检索不够”。** 固定规则抽取的 15 道来源会话已入 top-15 却非 exact 的中文题中，人工主诊断为评价/来源标注 5、提取或关系丢失 5、答案整合 2、检索缺关键记忆 1、时间金标未决 2。这些是机制样本，不能外推比例。它们足以否定“同场会话到了 top-15，就继续加邻居”的默认处方：`conv-30_qa5` 的三项住房偏好已在入槽记忆里，答题仍漏两项；`conv-43_qa96` 的主题曲与电影关系在摘要间断开，纯排序也不能修复。
3. **上游来源可信度和下游评测口径都会污染优化信号。** 当前归档的 1,780 个向量记忆 ID 均有会话 ID/日期，但无精确来源 turn；一场会话可有 10–47 turn。`conv-50_qa65` 的单例受控提取 POC 仅删除冲突图片 query，就把 9 月关系从错误瀑布接回钟楼，这是提取层的机制证据，尚无答题增益。另一端，旧严格分以宽松判错为预筛门；定向复判的 8 道对抗 wrong 中有 5 exact、2 partial、1 wrong，因此旧“373/444 wrong 即 84% 编造率”不成立，8 题也不能估总体率。任何 RSI 接受门都不能直接吃这些未经来源核验的标签。
4. **Jev 已经扩拉候选，却还没有展示“补到必要新事实”的闭环。** decider 的 732 道扩拉题有 418 道最终未选入近似对照候选池外 ID；laya 是 90/166。14 道“池外 ID 入槽且 Jev 独得”的定向人工复核，没有一题能明确把胜出归因于新增 ID 独有的金标必要事实。现有日志缺首判完整有序上下文，对照又是跨运行，这不是 Jev 机制无效的证明；它说明目前评分、扩拉和二判之间缺可验证的证据增量。首判每条记忆仅向服务展示前 60 字，且无日期；旧 AUC 约 0.53，应先记录真实可见证据，再设计触发器。
5. **RSI 仍是离线代理，不能给中文迭代背书。** 合成 run 的 train/validation/test 各两题，其他实验多以英语源 turn 覆盖代替生成答案；“金标支持路径”的冻结 test 还读取同一测试对话其他 QA 的 gold evidence。它可以提示“保护已有直接证据”和“接受局部更新需配对验证”，却没有显示中文、无金标、按时间顺序学习后的答案收益。

## 可操作的逐题判定顺序

对每道拟优化的中文题，先冻结题号、源数据版本、答案要素和评价口径，再走以下顺序。任何一步未核清，都不要把该题作为后一层的正例。

| 断点 | 先看什么 | 合适的小改动 | 不应据此声称 |
| --- | --- | --- | --- |
| 金标或来源有歧义 | 原始 turn 是否支持答案要素、说话者、可能性和日期精度；evidence ID 是否漏标 | 修评测注释或暂时隔离争议题，统一判分 | 模型/记忆功能失效 |
| 源正确，记忆主张缺失或错接 | 逐事实源 turn 集；文字、图片 query、caption 的冲突；相对日及关系是否保留 | 提取层来源标记、冲突门控、局部关系保真 | 图邻居或 Jev 扩拉救回了未入库事实 |
| 记忆有事实，却没进最终 15 条 | 同版本候选池与排序；新增 ID 的独有事实和挤出的旧证据 | 定向图桥接、证据保护槽位、受限重排 | 主题相关记忆就是答案证据 |
| 事实已在 15 条，答案仍错 | 列表要素、人物指代、计划与已发生、时间锚；提示展示顺序 | 仅改答题或展示接口的单变量消融 | 增加记忆数量能解决阅读/整合问题 |
| 答案忠于源，裁判仍翻分 | 同义、模态、额外正确细节、拒绝错误前提；同上下文重复结果 | judge-all 定向复核和统一细则 | exact 翻分等于真实能力变化 |

这个顺序不是说“先做所有上游工程才可研究图”。若已有一题满足“源事实准确、记忆已入库、无图前 15 条缺事实、图候选独有事实且能替换低价值槽位”，就可以直接做图的局部配对试验。图独见的八道入槽题已经人工核过：三个图独见 ID 均未直接提供金标必要事实，因此不应再在这八题上反复试图证明图收益；应寻找上述更有鉴别力的病例。

## 下一轮实验的优先队列与停止条件

| 优先级 | 最小验证 | 必须同时记录的反伤与退出条件 |
| --- | --- | --- |
| 1 | **建立可复核的事实支持侧车表。** 用已核过的时间、图片、跨会话事实、列表及关系病例，把每个记忆主张连到一个或多个源 turn，标记文字/query/caption、事件日期与会话日期、模态词。先只读，不自动改库。 | 未找到源支持的事实不得作为新召回的“收益”；跨会话 12 对记忆中 38 个拆分事实已有 36 个源支持、2 个公路同行者身份无源支持，且 6 对较晚版补有较早源细节，不能整条删除。 |
| 2 | **固定少量高鉴别力中文病例，分层做单变量 POC。** 提取层优先复现图片 query 冲突、相对日/关系丢失；答题层选必要事实已经入槽的列表/指代题；图层只选独有且可回源的缺事实候选。每个病例先写对照、唯一变化、模型调用上限和验收事实。 | 同时报告源事实覆盖、新旧 15 槽变化、答案要素、被挤出的直接证据、同上下文翻分；提取成功不可冒充答题成功。若无法找到源支持且图独有的病例，暂停扩大图复杂度。 |
| 3 | **修 Jev 留痕后测触发链。** 首判前后保存候选池、有序 15 条全文哈希、日期、来源、服务实际收到的文字、分数和二判理由；先做同一次运行内的证据增量审计。 | 若扩拉未选入新的必要事实或最终上下文未变，停止该题的二判调用；新候选若挤出已知直接证据，判为反伤。 |
| 4 | **待中文基线与前述接口稳定，再评 RSI。** 用无 gold 的过去经验生成候选，在独立、按时间后移的中文题上做父子版本配对，只有源支持与答案改善同时成立才接受局部更新。 | 不读取测试对话未来/同级 QA 的 gold evidence；保留旧题能力与调用账，失败回滚。 |

这些是试验设计，不是本轮已发生的结果。实际发起模型调用前应单独固定样本、次数、判据和预算；没有必要为本轮综合判断启动全量重跑。

## 数据边界与尚缺的证据

- 本地 HF LoCoMo 英中结构对齐，均为 1,986 QA、5,882 turn；这不验证逐句翻译。中文 LongMemEval-S 是 470/500 题，共同题中 293 题的背景少了 460 场；历史 LongMemEval 每文件最多 39 题且均英文。中文 LongMemEval 目前无效果数据，不能外推 LoCoMo 结论，也不能直接做英中分数比较。
- 八份中文主运行可见向量检索的 1,780 个 ID 与内容、会话元数据一致，增强了配对可比性；但未召回的完整库、图结构、服务状态和生成随机性没有冻结快照。六个只见于图候选的 ID 不能因此判为脏数据：五条当前向量库仍有，另一条有 ADD/DELETE 历史及源 turn 支持。它们中三条进入八道题的最终上下文，未见直接答案事实；这只是特殊样本。
- 2,042 次图入槽均无日期字段，其中 2,034 次可从归档中同 ID 向量记忆回填；另外八次中两次的 ID 当前向量库有日期，六次所属 ID 当前已删。回填**可能**修元数据透传，但事实级漏斗显示有些“昨天/上周”已在提取时消失；日期透传与相对日提取要分开验证。现有时间题 POC 以 gold 源 turn 做离线 oracle：45 个可算完整日期候选中 44 个合金标、一个发现年份冲突，不能当实时检索收益。
- EvoOntology 提供的方法类比是“主张到证据的映射、按失败层局部编辑、同条件配对接受”；论文数据智能体的分数不能迁移成这里的预期增益。
