## 二、58 轮实验的科学结论

### 有效成分（全部经同夜配对 + 复现轮双重验证）

1. **原子事实提取（最大效应，+10~+26 题）**：把 mem0 的"合并摘要式"提取（1829 条）重做为
   "一事一条"（4888 条）：人名/数字/计数逐字保留、列表逐项拆开、每条带会话锚定日期。
   独立向量池与主池 RRF 合流（原子 ×1.25 权重）。直接补上单跳缺口与列表缺项。
2. **Jev 证据充足停止（+6~+22 题）**：Laya 判定"上下文是否足以完整作答"（noul 概率），
   不足则聚合宽度加倍重拉一次。来自 Jev-Mem 论文（arXiv:2609.23986）的停止准则。
3. **rerank 保留**（关闭 -22）。

### 无效成分（同夜控变量后全部落入噪声带，已写入台账防重复）

- 图开关本身（终审 p=0.64）：融合图 vs 无图在全量上无统计差异
- 7 种图变体（实体/事件/偏好/主题/会话/月份/共现对/聚类/概念图）的所有组合方式
- 检索参数：聚合宽度、候选池大小、种子数、多采样自洽（answer_samples=3）
- Laya 问题路由（按题型调参）、Jev 四维候选过滤（阈值 0.35 偏激进，单独略负，待校准）

### 最重要的方法学发现：伪影是怎么产生的、怎么防

早期报告的三个"大效应"（精准措辞 +17、聚合宽度 +20、三图组合 +23）**复现轮全部失败**。
死因有两个，都大于任何真实配置效应：

1. **夜间条件漂移 ±15-20 题**：同一配置在不同夜晚跑分差 20+ 题（校准轮 323/333/335/347/348），
   跨夜比较全部不可信
2. **dev 集选择偏差**：dev 装满了参考臂的错题，任何新配置都有"新鲜机会"；
   dev 上 +6 的配置在从未参与选择的 test 对话上只剩 +1

**防线（本报告所有"有效"结论都过了这三道闸）**：同夜括号校准 → 复现轮 → test 对话保留。
这套流程本身是最有价值的产出——没有它，本报告会以"图组合 +23 题"的错误结论收场。

## 三、系统最终形态

```
原始对话（~9000 轮）
  │
  ├─ mem0 提取 ──→ 合并式记忆池（1829 条，chroma 主池）
  ├─ 原子提取 ──→ 原子事实池（4888 条，schema_rsi_atomic，一事一条+日期锚定）★新
  └─ 结构化提取 → 图谱（HugeGraph：9 类节点/2.6 万边，实体·事件·偏好·主题·
                  会话·月份·共现对·聚类·抽象概念）
                        │
检索：双池 RRF 合流 → 种子记忆顺图聚合召回 → Jev 四维过滤（待校准）
      → 统一 rerank 同预算 → Jev 证据充足判定（不足→扩拉一次）★新
      → 精准措辞作答 → glm-5.3 严格判分
```

关键组件：`extraction/atomic.py`、`llm/laya.py`（Laya/decider 双端点，多问合并单请求）、
`graph/variants.py`（7 变体注册表）、`scripts/search_rounds.py`（轮次跑批器，
支持 rerank/laya/jev_stop/atomic/answer_samples 轴）、`scripts/regrade_precision.py`
（双口径重判）、`docs/search_ledger.md`（append-only 实验台账）。

## 四、为什么不是 100 分（剩余差距归因）

当前 dev 精准 61.7%（对照 56.3%），全量约 71-72%。剩余 ~28pp 的构成：

| 缺口 | 量级 | 可攻性 |
|---|---|---|
| 提取密度不足（原子 5-25 条/会话，漏低频细节） | ~8-10pp | 高：提示词分级、二遍补提、密度校准 |
| 同义改写被判 partial（"purchased"vs"bought"） | ~6-8pp | 中：判分口径的固有代价，或答案措辞归一化 |
| 开放推理链（41.7% 封顶） | ~4pp | 低：模型推理能力问题 |
| 时间题长尾（相对日期、跨事件排序） | ~3-4pp | 中：事件图时序边 + 结构化日期约束输出 |
| 判分噪声（flash 内环 82.8% 一致率） | ~2pp | 已用 5.3 终审规避 |

**冲 100 分的现实路径不存在**——判分口径（全对且精确）下，同义改写和开放推理是
原理性缺口；现实上限估计 80-85%（提取密度打满 + 时间结构化 + 判分归一化）。
