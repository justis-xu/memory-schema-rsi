## 问题和运行边界

先前来源关系 V2 的首个请求因 HTTP 429 停止，0 个输出。用户本次明确告知 GLM 模型已可用，因此新建 V3 运行文件，不覆盖失败账。固定三个片段：真实的梅拉妮画动物与图片 caption（D13:8–10）、真实的乔恩／吉娜“我也是”跨轮赞同（D1:8–9）、合成的“只问最爱而未回答”反伤控制。每个片段用共同 JSON 结构跑基础提示和额外来源规则各一次；执行顺序为 AB、BA、AB。手工验收说明与 QA gold 不进入模型请求。

预定最多 **6 次** `glm-5.3-flash` 提取，每次最多 1200 completion tokens、temperature 0、SDK 重试 0、首败停止、不切端点；不调用答题、判分、检索、图服务，不写 Memory/Graph，也不拉取图片。验收分别看原子事实、主体、合法且足够的源 turn、文本/caption 渠道和无源偏好反伤。

## 实际运行与逐例验收

六次预定请求全部有输出且是可解析 JSON，总计 1,950 prompt tokens、368 completion tokens。旧 429 已不代表本次推理状态；这只证明当前小请求可完成，不代表后续额度或服务稳定。

| 吉娜“我也是” | 吉娜只引 D1:9，其正面评价可支持实际输出的“喜欢”，但未记录“我也是”承接的 D1:8；写成“喜欢现代舞” | 吉娜引 D1:8+D1:9，主体正确；仍只写“喜欢现代舞” | 两臂都弱化了有源支持的“现代舞是最爱”，来源规则补全承接关系却没有保住偏好强度 |

两个真实片段里，输出的源 ID 都能在输入中找到，也能支持其实际写出的较弱事实；**合法指针不等于完整的来源关系或事实保真**。例如 D1:9 可以支持吉娜喜欢现代舞，但“我也是”承接的最爱语义在 D1:8。追加来源规则后，这两处跨轮指针都补全；同时它未把吉娜的强度从“喜欢”恢复到“最爱”。不能只用指针准确率验收事实保真。

## 结论、置信度、下一步优化建议

**结论：** 在这六次定向输出中，来源规则提示帮助模型补全两处跨轮引用，且三例未出现检查范围内的无源偏好；但吉娜的独有强度信息仍丢失，caption 独有事实没有被提取。提取接口可运行，自动事实对齐与保真尚未通过完整验收，更没有答题净收益证据。

**置信度：** 对请求数、原始响应、源 ID 是否存在和逐项遗漏为高；“吉娜最爱”的跨轮语义人工判断为中高。样本非随机、每臂仅一次，不能估计总体质量、稳定性或规则净收益。没有比较历史 Mem0 的原始提示与输出。

**下一步：** 在固定 12 对跨场重复里挑有源独有细节与无源身份各一对，沿用同一源 turn 契约，逐事实验收“旧细节保留、无源撤回、两个场次正确区分”。同时补一个必须从 caption 提取的诊断样本，验收渠道标签。再考虑少量重复采样；若要评估答题收益，另用冻结候选和槽位做配对答题及反伤，不把本阶段提取改善直接转为收益宣称。
