## 结论、置信度与下一步优化建议

**结论：** 这对中文题展示了一个具体的“错人前提→召回转向另一人→用邻近但不相干的活动填答案”链条。Graph 和 Jev 在这四份历史运行中没有把已入库的反证带进 `qa233` 最终上下文。这里的反证是“活动属于黛博拉”，不意味着已经证明乔琳从未与自己妈妈的朋友见面。来源事实核验和回答错误前提，须与普通事实补全分开。

**置信度：** 题面一词差异、源话说话者、归档候选位次、最终 ID 交集、答案及目标 ID 当时存在为高；“饭局不是所问活动”为人工对人物/时间/谓词的逐项判断，置信度高。为什么目标记忆在 `qa233` 连候选都没进，旧日志只保存重排后的 `retrieved_memories`，**没有粗排向量池和得分**，所以无法定位到 embedding 首召还是 rerank 筛除；Graph 的种子和未截断邻居也缺失。四次运行并非独立样本，不能估算普遍发生率或组件因果增益。

**下一步优化建议：** 在当前纯中文库固定同一记忆版本，做原问与“去掉题目人物、保留关系词”的小规模召回对照，另用正确人物问句作只读上界；记录粗排前 45、重排前 15、目标/干扰 ID 和被挤出的直证。部署策略仍要根据原问题的人物核关系，不能把去名召回的黛博拉活动直接回填给乔琳。未来评测保存粗排候选、重排输入输出、图种子及来源 turn，才能辨别断点并验收反伤。
