# 归并写入门槛离线回放：结构校验能拦什么、漏什么

## 门槛和验收口径

对每份输出独立检查：严格 JSON、必填字段、`source_turn_ids` 是否在输入、`source_session_id` 是否与 `dia_id` 一致、记忆 ID 是否属于本病例；`absent` 不可被接受，`partial` 不可直接保留/合并，来源有证但不在候选记忆的 `full` 事实不可标“撤回”。任一项失败即拒绝整份输出。为分析错误原因，可以离线读出完整 Markdown 围栏内的 JSON，但**围栏输出依然不通过严格接口**。

门槛只使用模型请求、响应及输入 ID。上阶段人工事实表不参与门槛判定，只在回放后比较“结构通过”与真实语义风险。`partial` 一律拒绝是本次保守规则，不是已量出的最佳生产阈值。

合计 **5/6 拒绝、1/6 结构通过**。这不是 5 份“有效防伤”与 1 份“安全”：唯一通过者已有明确事实遗漏，拒绝者也可能只是撞上无关结构错误。为检验门槛是否真正识别无源身份，另做**纯离线反事实敏感性检查**：只从调用 5 的输出移除一条无关的 `partial` 年份行，保留其余三条带“朋友”的错误事实，结构门槛随即通过。该变体不是模型生成，也未写入库；它证明当前门槛对关键身份伤害没有防护能力。

## 结论、置信度、下一步优化建议

**结论：** 严格解析、来源位置、病例 ID 和动作一致性值得保留为第一道拒绝门槛，但不能把“通过”解释为有源事实保真。当前输出同时把“来源有证”“候选记忆覆盖”“可执行动作”混在一行；只检查这些自报字段，会漏掉陶艺限定语，也会接受没有结构警报的错误同行身份。上阶段 48 条事实的源 ID 全合法仍不足以证明语义支持。

**置信度：** 规则执行、六份原始输出、5/1 结果和离线变体为高；陶艺限定语、朋友身份和 2022 年源证据由已回源人工核查，置信度中高。样本固定且小，不能估计生产拦截率或模型稳定性；门槛尚未接到写入路径，不能声称生产数据受保护。

**下一步：** 定义不可混写的原子字段：`source_support`（full/partial/absent）、`memory_coverage`（每个候选 full/partial/absent）、`source_only`、来源渠道与时间推导，再由独立规划器生成归并动作。执行前仍需做子句级反伤：无源身份不得出现在任何待接受句；每个有源独有事实与限定语必须有保留载体。先在固定 12 对和两条真实当前载体风险上离线验收这个契约，再讨论小规模模型输出和独立的配对答题净收益。
