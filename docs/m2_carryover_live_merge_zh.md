> 2026-09-28。承接 [12 对逐事实审计](m2_carryover_fact_merge_zh.md)、[当前中文事实载体](m2_carryover_current_witnesses_zh.md) 与 [来源关系 V3](m2_source_relations_v3_zh.md)。固定请求、原始输出和用量见 `results/analysis/m2_carryover_live_merge_v1_20260928.json`，人工逐例验收见 `results/analysis/m2_carryover_live_merge_review_20260928.json`；请求脚本为 `scripts/m2_poc_carryover_live_merge.py`，结构复核脚本为 `scripts/m2_verify_carryover_live_merge.py`。这不是历史 Mem0 提取重放，也没有改线上记忆。

## 固定样本、对照和调用边界

从已有中文源审计中选三个输入包、四个病例：蒂姆同一来源场的**写作**与**英国城堡**两对记忆；梅拉妮**暂停陶艺**的两版记忆；当前中文记忆“约翰**和朋友**公路旅行”的来源核查。前两包给两版中文记忆，公路旅行包给当前一条中文记忆；每包提供相关**完整**源场次的中文原话、`dia_id`、说话者和场次日期，不用人工事实表挑几句“正确答案”喂模型。图片原始 caption/query 随 turn 标记提供，但没有下载或查看图片。

每包基础提示与额外来源约束提示各一次，顺序 AB、BA、AB。两臂共用原子事实 JSON 字段；约束臂强调来源场次与写入场次、旧新版独有细节、他人猜测与本人自述、限定语和无源同行身份。人工验收标签及 QA gold 没进入请求。预定上限 **6 次 GLM 提取**、每次最多 2,200 completion tokens、temperature 0、SDK 重试 0、首败停止；不调用答题、判分或检索模型，不写 Memory/Graph。

实际六次均返回，总计 14,725 prompt tokens、6,097 completion tokens。五份严格 JSON；蒂姆来源约束臂返回了完整 Markdown JSON 代码围栏，违反纯 JSON 协议，但去掉**包住整份响应的围栏**后可离线解析，未额外调用模型。六份解析后共 48 条输出事实；源 `dia_id` 均在所给 turn 中，场次字段与 ID 对应；基础臂有两处事实的 `case_id` 与所列记忆 ID 属于不同病例。指针合法性并未确保语义、覆盖或动作正确。

## 结论、置信度、下一步优化建议

**结论：** 在完整中文源会话已给定的条件下，来源约束提示可帮助拆出蒂姆写作/城堡的晚版独有事实，并补回陶艺情绪限定语；它仍会错误声明记忆正文覆盖、把来源存在但未收录的事实与无源主张同叫“撤回”，还会在公路旅行上同时写“撤回朋友”和“合并含朋友的句子”。因此当前 JSON **不能作为自动归并/删除指令**。源 ID 全合法并不构成上线门槛通过。

**置信度：** 对固定请求、原始输出、源 turn、指针存在性和上述具体矛盾为高；事实粒度与语义支持属于人工定向判断，为中高。四个病例非随机，每臂一次；完整来源已直接提供，没有测自动回源、运行时提取稳定性、全库错误率或答题净收益。

**下一步优化建议：**

1. 将“来源支持”与“候选记忆覆盖”拆成两个独立判定；候选未收录但源有证应是 `source_only`，不能和 `unsupported` 共用撤回动作。每个接受子句须有候选 ID、源场次、源 turn 与 `text/image_caption` 渠道。
2. 在执行任何归并前做**整句反伤校验**：若被撤回的身份/强情绪仍出现在任一待保留或待合并句，拒绝整个操作；日期锚可计算的年份要独立核查，不因缺字面“2022”撤回。
3. 用这四例及固定 12 对离线验收“独有细节不丢、无源子句不残留、来源与记忆覆盖分别正确”，再做小规模重复提取。检索入槽和答案净收益必须另立同条件配对阶段，不能由本阶段输出事实变化直接推出。
