# 中文 RSI 原型的词面检索可达性

> 2026-09-27。只读脚本 `scripts/m2_audit_zh_rsi_lexical_reachability.py`，逐题机器结果 `results/analysis/m2_zh_rsi_lexical_reachability_20260927.json`。核对 `experiments/schema_rsi/schema_rsi_lab/{lifecycle,provenance,graph_only,support_miner}.py`、中文/英文 LoCoMo 原始数据和当前 `zhfull` Chroma 记忆。零模型、零图服务、零答题调用。

## 问题与方法

RSI 历史证据几乎来自英文；如果直接把实验原型拿来做中文无金标验证，它的来源链接、图扩拉和成功路径挖掘能否接触中文问题？本轮只查**代码上的词面入口**，不测答案效果。

原型的 `_tokens` / `_terms` 都用 `[a-z0-9]+` 提词，过滤长度不足 3 的词。`SourceGraph.for_question` 虽可从前几个记忆 ID、关联会话和问题词索引收集源 turn，最终仍要求 `_overlap(question, turn) >= 0.3`；`LifecycleGraph.for_question` 对图邻居也要求 `_overlap(question, memory) >= 0.12`。问题没有此类词时，两个重叠分数必为 0，候选无法过门。`GraphOnlyRetriever.keyword` 在空词集时无倒排命中；`support_miner` 明确在 `query_terms` 为空时返回空列表。`before_extract` 的词面种子也依赖相同 `_overlap`。

按实际 tokenizer 对英中对齐的 1,986 道题提词；原始 turn 文本使用项目的 LoCoMo adapter 格式，包括现有图片说明/图片 query。对每道题，在**同一对话所有源 turn** 中取最大重叠，作为来源门槛的宽松上界；对当前同用户的全部 1,800 条 `zhfull` 记忆取最大重叠，作为图候选门槛的宽松上界。实际原型还要经过种子、图路径、会话、15 槽等限制，可达数只会更少或相同。机器结果保存数据哈希、记忆 ID/正文/用户/会话哈希、逐题词集与最大重叠，便于复算。

## 直接观察

| 项目 | 英文 LoCoMo | 中文 LoCoMo |
| --- | ---: | ---: |
| 题目数 | 1,986 | 1,986 |
| 问题提不出任何词 | 0 | **1,700** |
| 只提到数字词 | 0 | **252** |
| 与同对话任一源 turn 共享至少一词 | 1,986 | **35** |
| 与同对话任一源 turn 达到 0.3 门槛的上界 | 1,843 | **35** |
| 源 turn 总数 / 完全提不出词 | 5,882 / 2 | 5,882 / **4,573** |

当前 `zhfull` 1,800 条中文记忆中，**774 条**也提不出词。中文题目与同用户任一当前记忆有词面交集、并达到 0.12 门槛的上界均为 **280/1,986**；这 280 道很多靠年份或英文专名匹配，不能视为必要事实可达。此前预选 20 题中 19 题无词，剩下的 `conv-43_qa32` 只提到 `2023`，在同对话原始 turn 中最大重叠为 0。因此这一组 20 题按当前 `SourceGraph` 词面门槛均无法选入源 turn，即使对应记忆在现库中存在。这里的“无法”只针对该原型的这一条路径。

不同于“中文一律零词”，仍有 286 道题带 ASCII 数字或英文名；只有 35 道能碰到同对话源 turn，典型词包括 `lgbtq`、`youtube`、`frank/ocean`，也有 `2010`、`2077`。后者只说明字符碰巧重叠，并不证明找到了答题所需证据。按类别分别的分母和上界已在 JSON 中保存。

## 结论、置信度与优化建议

**结论：** 当前 RSI 实验原型的词面路径对大多数中文问题在入口处失效。此前英语上观察到的来源召回或 success path 增益，不能在不改词面接口的情况下当作中文 RSI 预期。这个结论**不适用于**生产 Mem0 向量检索或 HugeGraph 服务；它们有不同候选生成与打分路径。本轮也不证明换分词器就会改善中文答案。

**置信度：** 正则表达式、阈值、代码分支和词集数量可直接复算，置信度高；“同对话所有 turn/全部当前用户记忆”是故意放宽的结构上界，不是实际运行的召回率。原始 gold evidence 不完整、图片字段可能带英文、数字/专名匹配可能无关，均阻止把 35 或 280 解释为正确证据数量。

**下一步：** 在隔离的离线原型中先替换中文词面候选器，再固定同一批源 turn/记忆/问题，比较候选覆盖、每题候选数、源支持和误连；先通过人物、动作、时间及“已发生/计划/获得”的关系检查，再进入答题。候选器可先以中文字符 n-gram、分词或已存在的向量检索作为对照，但不能只追求把 1,700 个空词问题变成非空，也必须记录误召和额外开销。生产图、Jev、RSI 接受门继续保持独立验证。
