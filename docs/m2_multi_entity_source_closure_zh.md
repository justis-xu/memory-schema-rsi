## 对旧结果的修正范围

此前 [8 题答题 POC](/Users/xu/git/memory-schema-rsi/docs/m2_multi_entity_cohort_answer_poc_zh.md)按**中文金标必要字面要素**标 `conv-42_qa42` 原问 1/2、拆问合并 2/2，并记录合并一次把《美丽心灵的永恒阳光》“计划看”误列为已看。本次回源又发现金标要求的《指环王》双人“看过”缺内特直接证据。旧标签仍是“是否命中数据集金标”的有效记录，但它**不能用来证明**合并臂新增了有源的共同观影事实。合并输出还把《指环王》称为内特最爱之一，当前核到的 `D10:1` 也不支持“最爱”。不能据此简单重算整份历史总分；本审计只确认这一个金标要素的来源不足。

这与 `conv-42_qa71` 不同：自然之美的金标双人原话完整，当前问题主要是记忆保留与检索；电影题则先有**金标关系证据不足**，即使模型照金标答出《指环王》也可能扩大来源。两类问题需要不同的优化和评测处理。

## 结论、置信度与下一步优化建议

**结论：** 固定 8 题中，日落题依赖图片 caption，乌龟题依赖语境性“喜欢”推断，电影题的一个金标要素把“推荐”推进到“双人看过”而没有直接来源；其余题的核心双方关系在源话中可核。这是源证据类型与关系状态的病例清单，不能当全库质量比例。它修正了此前电影题“合并多命中一次必要事实”可解释为检索收益的范围。

**置信度：** 中英 QA/evidence 一致性、片名在整段对话正文中的唯一出现、源话/当前同场记忆文本为高；乌龟“喜欢”的程度是人工语义判断，中；电影推荐是否意味着内特实际看过仍未知，不能把缺直接证据反说成“确定没看过”。当前记忆只按 session 对齐，没有逐 `dia_id` 证明生成来源。

**下一步：** 在中文配对 POC 入选前增加一个源关系门槛：按人物、谓词、状态与模态列出每个金标要素的证据，并单列“可推断”与“未证实”。针对真正有双人直证而记忆或检索缺失的题，再测候选净入槽和答案反伤；电影题保留为评测标签敏感性病例，不以其《指环王》命中作为 Graph/Jev/RSI 收益。来源字段长期应支持逐事实 `dia_id`，否则难以自动执行这个门槛。
