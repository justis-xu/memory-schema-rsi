# 当前中文签名篮球题：图桥存在，但候选截断不稳

> 2026-09-27。隔离进程内重放，不写 HugeGraph、Chroma，不调用向量、重排、答题或裁判模型。脚本：`scripts/m2_replay_signed_ball_graph.py`；机器结果：`results/analysis/m2_signed_ball_graph_replay_20260927.json`。

## 问题与样本

定向病例 `locomo_conv-43_qa25` 问“蒂姆和约翰拥有什么相似的运动收藏品？”。当前无图答题缺约翰的签名篮球；人工单槽补位曾让该题的两个必要事实到达答案，但自动图路径未证实。本轮只问：**在现有代码的五条种子、单节点 15 条、图候选最多 30 条约束下，共用 `signed basketball` 实体能否把约翰记忆送进图候选池？**

固定输入是此前当前库的重排前 15 条，其中前 5 条作图种子，蒂姆签名篮球位于第 4；约翰签名篮球不在前 15。当前 `conv-43` 共 211 条记忆，199 条有结构缓存、209 条有主题缓存、211 条有嵌入缓存。整个当前 Chroma 的 ID/正文/用户/场次逻辑指纹仍为 `61e015ce…`，与前次缓存对齐审计相同；本轮 SQLite 文件哈希前后均为 `57152cd4…`。

## 方法与直接观测

用生产 `GraphBuilder.build_s1`、`build_concepts`、`GraphRetriever.retrieve_fused` 和 V8 的 `_kmeans`，把当前 211 条记忆与已有缓存送进隔离的进程内图。缺结构/主题缓存的 ID 仍有 Memory 顶点，但不临时补抽取。进程内图模拟 `HugeGraphStore.get_neighbors` 的方向、`limit * 2` 原始边窗口、标签过滤和去重。S2 固定顺序图有 713 个顶点、1,577 条边。该实体只有两条 Memory 入边，恰为蒂姆和约翰的签名篮球记忆，因此**局部桥本身没有歧义**。

| 重放条件 | 约翰记忆在图候选中的位置 |
| --- | --- |
| S1，仅结构化节点，按 ID 升序建图 | 无上限时第 40；截为前 30 后缺席 |
| S2，加受控主题，按 ID 升序 | 第 7，进入前 30 |
| S2 + V8 聚类，按 ID 升序 | 第 6，进入前 30 |
| S2 / S2+V8，按 ID 降序 | 都未进前 30 |
| 固定种子的顺序扰动 | S2 的 50 次中 29 次进前 30；S2+V8 的 20 次中 8 次进前 30 |

S2 的 50 次顺序扰动里，约翰记忆在**未截断**的图候选中每次都可达，位置从第 1 到第 78；所以本病例的主要断点不是缺 `signed basketball` 边，而是候选排序和 30 条截断。按 ID 升序的 S2 中，约翰获得 `concept:sports`、`concept:friends`、`entity:signed basketball` 三个 support，排第 7；宽人物或通用主题节点的 15 条邻居限额会随边枚举顺序改变其 support。当前排序只数不同节点的 support，不区分稀有的精确物品桥与泛用人物/主题节点。顺序扰动只是机制压力测试，**29/50 和 8/20 不是线上成功率估计**。

## 结论、置信度和限制

**结论：** 这个有源、当前记忆仍在库中的多实体病例，图确实有一条可用的精确实体桥；然而按现有融合检索的节点限额与 support 排序，桥接事实并不稳定进入图候选前 30。S2/V8 可能让它靠更多节点排前，也可能让泛主题候选竞争更激烈。只要没有进入 30 条，最终统一重排和答题就无从利用它。

对“当前两条缓存记忆共用实体”和“隔离重放在给定顺序下的具体候选位置”置信度高；对真实 HugeGraph 当下的候选顺序及答案收益**未知**。本轮未建真实隔离 HugeGraph；HugeGraph 的边枚举顺序未证实等同进程内顺序。缓存只按 ID 命中，没有原正文哈希；除这两条人工检查过的关键记忆外，其他缓存主张尚不能视为源忠实。旧向量前 15 来自此前一次当前库探针，不是同次运行的实时检索；V8 使用现有嵌入，没有补算缺失数据。本轮也没有最终融合重排、入槽或答案对照。

## 下一步优化验证

1. 在隔离图里记录每个图候选的种子、节点、节点度、原始边次序和截断原因；先核真实 HugeGraph 与进程内重放的差异，再考虑任何全量建图。
2. 在预选的中文多人题队列中对比现行 support 排序与“源可核、稀有关系桥优先”的候选策略；固定向量前 15 和相同 15 槽，逐题统计必要事实进入、直接证据被挤出及新增旁支。不能只展示签名篮球一个正例。
3. 候选层出现可重复的净改善后，才做小型 ABBA 答题对照。此前人工补位 2/2 只是上界病例，不能当自动图收益。
