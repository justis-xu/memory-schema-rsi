# 当前中文结构缓存与独立图病例的就绪边界

## 问题、范围与方法

真实配置实例没有当前中文图，需要准备独立当前源实验。本轮核全10个中文主轨道对话的本地S1缓存能否完整覆盖，并回放部分缓存构图，检查Memory顶点覆盖是否会掩盖关系缺失。

当前源为SQLite只读主轨道1,800条；缓存为 `data/graph_zh/structured_cache.json` 全1,705条。逐ID匹配后，对每user在全新内存记录器执行真实build_s1，**仅提供现有缓存，不运行extractor补提取**。这是显式部分缓存诊断，不代表真实入口执行时一定如此：正常入口还会尝试对missing ID调用提取器，成功则可补齐。

脚本 `scripts/m2_audit_current_cache_graph_readiness.py`；结果 `results/analysis/m2_current_cache_graph_readiness_20260928.json`。另保存conv-26唯一缺项的人工源话例包 `results/analysis/m2_current_cache_missing_example_20260928.json`。零模型调用、零真实图写入，源逻辑指纹前后一致。

四个接受回放共写齐637个Memory，581条有派生出边、56个missing Memory无边；缓存命中者本轮没有全空或无边记录。因此单凭图Memory数量与当前清单相等，会把未处理56条也计作“已齐”。不能把无边本身当作失败：其他数据可能合法空提取，应依逐ID成功状态区分。

缓存命中也不等于成功的当前版语义提取：旧格式没有原正文/模型/提示指纹、源turn或处理状态。即使补上1,219个缺项，也不能自动宣告其余581条已通过来源验收。

## 定向缺项：conv-26喜欢画动物

ID `64e65e18-3b0e-4e64-9145-97b5608c65cd` 是conv-26唯一缺项。当前记忆写梅拉妮喜欢画动物、平静特别、最近画马、木板墙等。

人工源话回看：D13:8梅拉妮展示最近画的马；D13:9卡罗琳问是否喜欢画动物；D13:10梅拉妮肯定并说画动物让人平静特别、马优雅。木板墙细节在图片caption，不在本人文本。这条偏好由问答共同支持，不能只拿D13:10的“是的”脱离前问，也不应把caption描述伪装成本人明确自述。

本阶段仅定位这一个缺项的来源，不验证全部581条缓存语义，不证明其与任何QA构成独有必要事实。可作为下一步当前版提取关系控制，不应因只缺1条而把整个conv-26当成已核干净图。

## 结论、置信度与下一步

- **高置信度，当前ID覆盖/真实构建器回放：** 缓存尚不足以直接发布任一完整中文对话图；部分覆盖能产生Memory全齐但关系不齐的产物。
- **高置信度，单例源话人工判断：** 画动物偏好需要相邻问答，木板墙需要图片caption来源类别。现有S1只有Memory正文，无法自行还原这两种来源区别。
- **未知：** 当前自动补提取的质量、既有缓存语义可靠性、完整图后的候选变化与中文答题净收益。没有模型/嵌入/主题/聚类或重排实验。

下一步分开推进：

1. 把此画动物关系加入已有吉娜赞同/内特语境提取病例的当前源控制，保留源turn与支持等级；若服务可用才做有调用账的少量中文提取验证。
2. 独立研究图的发布验收要同时记录Memory身份覆盖、逐ID处理状态、关系构建版本；不以Memory数量判就绪，也不凭旧缓存命中推成功。
3. 当前缓存仅可构建明确标注partial/provenance unknown的诊断图，不能作为净收益基线。真正Graph对照需固定完整当前源、可核关系和相同候选预算。
4. 此覆盖问题本轮已核全10user，不继续反复统计。下一阶段回到来源关系的真实提取能力或固定候选机制实验，把基础防线与答案收益分开报告。
