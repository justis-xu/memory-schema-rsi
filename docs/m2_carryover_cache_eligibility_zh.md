## 先订正旧事实标签

旧 `m2_carryover_fact_inventory_20260926.json` 的 38 项事实和合并原型保留为历史版本，但有两处**文本覆盖判断不准确**：

1. 梅拉妮晚版记忆只写“暂停陶艺……这让她很难受”，**没写**她本人在 `D17:10` 的限定语“但我还好”。旧标签“暂停陶艺让她难受，但她说自己还好”却标晚版覆盖，过度宣称了来源保全。订正为“暂停陶艺让她难受”，并单记“但我还好”仍被两版遗漏。
2. 蒂姆较早版已经写“写作带给他巨大快乐”，晚版才补“写作能创造全新的世界”。旧标签把“快乐，并创造全新世界”整句标成晚版独有。现拆成共同事实“写作带来快乐”与晚版独有事实“创造全新世界”。

订正后为 **39 项、37 项有源、2 项无源**；其中两版共有 26 项、仅晚版有 6 项、仅早版有 5 项。旧版的 38/36/2 计数是旧复合粒度，不能与新版混用；六项晚版独有的**数量**没有变化，但“难受但还好”和“快乐并创造世界”的旧表述已撤回。新结果保存全量订正事实与合并建议，旧文件不被覆盖。

## 逐对核缓存资格

12 对的记忆元数据均显示旧源 `session_n` → 较晚写入 `session_(n+1)`，Mem0 `history` 中两端正文与归档一致，且旧 ADD 时间早于晚 ADD。重放旧源场次后，缓存留下日期锚及该场 `D<n>:1–9`。按**晚版实际写到且已有旧源 turn 支持**的 32 项逐项比对，31 项至少一个已核源 turn 在这 9 个 turn 内；11 对的晚版有源子句全部符合这个位置条件。

| 对话与旧→晚场次 | 晚版有源事实的源 turn 在缓存中 | 例外 |
| --- | ---: | --- |
| `conv-41` 22→23，家庭照 | 4/4 | 无 |
| `conv-44` 22→23，回收首饰 | 2/2 | 无 |
| `conv-44` 15→16，四只狗 | 2/2 | 无 |
| `conv-44` 22→23，首饰捐赠 | 3/3 | 无 |
| `conv-43` 15→16，写作 | 4/4 | 含订正后共同的快乐与晚版独有的创造世界 |
| `conv-43` 27→28，旅行者群体 | 2/2 | 无 |
| `conv-26` 17→18，陶艺暂停 | **1/2** | 本人 `D17:10` 的“难受，但我还好”不在缓存 |

陶艺例尤其不能只看词面：缓存里有卡罗琳 `D17:9` 推测“暂停一定很不好受”，但**没有**梅拉妮 `D17:10` 本人说“确实挺难受的，但我还好”。晚版写“这让她很难受”虽然恰好得到本人原话的一部分支持，历史提取器可能看到的缓存通道只给出了**对方推测**。不能凭晚版文本与本人原话相符，就断定它当时从本人原话抽出；`Existing Memories` 或其他未留存输入也可能参与。公路旅行的“玛丽亚同行”仍无指定源会话支持，缓存位置不能为它补证。

## 结论、置信度与下一步

**结论：** 上一阶段发现的缓存顺序错误与固定 12 对跨场重复的输入条件高度吻合：全是相邻场次，31/32 项晚版有源事实在本机回放的前场缓存中可见。它提供了**系统性可行路径**，但不是“12 对均由缓存导致”的因果证明。修正缓存顺序可消除该路径中的前场开头事实，仍不能阻断旧记忆检索、模型从对方推测补细节或无源身份生成。

**置信度：** 两端记忆正文、`history` ADD 顺序、场次相邻、当前源码缓存回放及 turn 位置为高；复合子句覆盖订正为人工判断，置信度中高。历史提取提示、向量 top 10、模型回复未留存，通道归因与实际线上改善未知。样本是先经词面候选再人工筛出的旧事实重复对，31/32 不能当全库发生频率。

**下一步优化建议：** 先用这 12 对做离线门控设计：每个输出子句区分本场新 turn、历史 turn、他人推测和图片 query；无本场证据的旧事实应链接旧记忆或补回旧源，而不是以新场元数据再 ADD。陶艺例单独验收“难受”与“但我还好”两子句，并保护读书画画的旧版直证；公路同行者身份必须撤回。随后用少量中文真实提取调用验证模型能否产出可核 turn ID，再独立检验答案与反伤，不把缓存 POC 或人工 oracle 当成答题收益。
