# 中文失分漏斗：逐题证据核查（第一批）

日期：2026-09-26。目的：把“图或 Jev 没涨分”拆为更具体的问题，决定下一笔实验预算花在哪里。

## 数据可比性

使用 2026-09-25 中文首轮逐题结果 `results_zh/zhfull_locomo_20260925_115806.jsonl`、严格重判 `results/precision_regrade_zhfull.jsonl`、翻译版 LoCoMo 的金标 dia_id、当前 Chroma 中相同 user 的记忆。当前库经过 9 月 26 日局部重灌，因此**只检查 ID 保持不变的对话**：conv-26/30/43/44 的历史召回唯一 ID 与现库交集分别是 138/138、102/102、211/211、181/181；其他六对话为 0，不跨版本归因。以下逐题数据均来自前三个保持不变的对话。

“金标答案在记忆里”不等于“支持事实在记忆里”，特别是时间推算、同义表达和多跳题。每例同时看源 turn、完整记忆池、检索 top-15、最终答案和判分理由；阶段判断仅针对所列事实。

## 六个机制不同的失分例

| case | 源证据与记忆流向 | 答案/判分 | 最接近的失效环节 |
|---|---|---|---|
| **conv-30_qa37**：吉娜何时提到希亚·拉博夫？ | 源 `D19:4` 明确说“是希亚·拉博夫！”，会话日期给出 2023-07-23；当前该对话 102 条记忆里“希亚/拉博夫”均 0 条，历史召回也没有 | 答案说记忆中没有记录；归档 wrong、`judge=null` | **写入/提取漏掉低频实体**。扩图、扩拉无法从当前池救回；应优先测补提 |
| **conv-43_qa21**：约翰提过哪些美国城市？ | 金标三个源 turn 为西雅图/芝加哥/纽约。三城在 211 条记忆里都有，芝加哥和纽约在 top-15；西雅图只在全池，不在召回 | 答芝加哥、纽约；严格判 partial，明确缺“西雅图” | **检索/候选覆盖**。有针对多实体清单的补召回机会；但源西雅图 turn 同时提“下个月在那里比赛”，需核准 gold 对“去过”的时间口径 |
| **conv-43_qa96**：蒂姆最喜欢弹哪部电影的主题曲？ | 源 `D8:14` 说“喜欢的电影的主题曲”，`D8:16` 说《哈利·波特与魔法石》；两段对应记忆**都在 top-15**，还混入“蒂姆最喜欢《星球大战》系列” | 答《星球大战》，归档 wrong、`judge=null` | **跨 turn 关系丢失或回答误连**。扩大召回本身难救；需保留引用范围、说话人及相邻 turn 关系 |
| **conv-26_qa43**：卡罗琳创作什么类型的艺术？ | “尝试抽象绘画风格”的记忆在 top-15 | 答案末尾确实提“近期开始尝试抽象绘画风格”；严格判 partial，理由是没有把“抽象艺术”作为直接类型作答 | **回答聚焦/判分边界**。证据已在场；不能算提取或检索缺失 |
| **conv-43_qa2**：约翰收集什么？ | 球鞋、电影 DVD、球衣三条金标事实依次排在 top-15 的第 3、2、1 位 | 答案三项都包含，但额外写了“书籍”；严格判 partial，理由为额外收藏品不在金标 | **过度补充/严格口径**。不应为此加更多图候选；宜约束只列有“收藏”关系的物品 |
| **conv-43_qa67**：旅行梦想下可培养何种爱好？ | 源证据显示蒂姆写文章、写小说、喜欢旅行；金标“写旅行博客”是推论，源 turn 与记忆里没有这句话 | 答“学意大利语、读旅行书、结合写作与音乐”，严格判 wrong | **开放推理单一金标**。其他建议未必无理；这是评测口径与推理选择问题，图召回难直接解决 |

前三例已经覆盖三种不同路径：**源事实没有进入池 → 池中有但没入候选 → 上下文齐全但关系/答案错**。把三者统称“图召回差”会把预算投错地方。

## 保守的批量词面探针

在 conv-26/30/43/44 的中文首轮 single-hop 非 exact 中，只取金标去空白/标点后长度 3–24 且不含列表分隔符的 52 题，检查**完整 gold 字符串**是否在当前同 ID 记忆池或历史 top-15 里：

| 位置 | 题数 |
|---|---:|
| 全池出现字面 gold | 10/52 |
| top-15 出现字面 gold | 5/52 |
| 全池有、top-15 无 | 5/52 |
| 全池无完整字面 gold | 42/52 |

这只是**字面子串探针**，可证实至少 5 道“池中有、上下文没有”和 5 道“上下文有但仍失分”的候选；42 道无字面命中可能是同义改写、日期推算、关系型回答、标注问题或真提取缺失，不能把 42 全归因于提取。下一批应人工标注这些题的源事实和记忆语义覆盖，而不是扩大词面指标的解释范围。

## 金标来源会话能否到达上下文

另用 `scripts/audit_evidence_sessions.py` 从中文金标 `D数字:turn` 提取来源 session，与历史首轮 top-15 的 `session_id` 对照；完整池只取上述四个对话的历史召回 ID 并查现库的同 ID 元数据，排除 conv-44 后来新增的 5 条记忆。四对话历史共 632 个不同的召回 ID，全部仍在现库，session 元数据逐 ID 一致。机器结果：`results/analysis/evidence_session_audit_20260926.json`。

530 道有可解析来源证据的 J 类题中，严格 exact 为 349，非 exact 为 181。解析兼容金标中合写的 `D8:6; D9:17` 和异常写法 `D:11:26`：

| 金标来源 session 的到达位置 | 全题 | exact | 非 exact |
|---|---:|---:|---:|
| 全部在 top-15 | 485 | 339 | **146** |
| 全部在池里，但至少一个没进 top-15 | 43 | 10 | **33** |
| 至少一个在历史 ID 池中缺失 | 2 | 0 | **2** |

分题型看，单跳 272 道的全部来源 session 在 top-15，其中 62 道仍非 exact；多跳对应 81/23，开放题 24/16，时间题 108/45（前数为来源 session 齐全的题数，后数为其中非 exact 数）。**会话覆盖不是事实覆盖**：一条同 session 的记忆可能只记住主题，漏掉金标 turn 的具体内容。这个统计因此不能把 146 道归为“推理/生成错误”，只能说明“继续加宽到更多 session”对它们缺乏直接证据；应先抽查同 session 的具体事实是否保留。池有 session 而 top-15 没有的 33 道则是更集中的检索候选，但仍需确认池里是否保留了答案事实。两道池缺来源 session 的是 conv-30_qa37/38，优先查提取。

在 top-15 来源 session 齐全但非 exact 的 146 道里，严格重判为 **102 partial、44 wrong**；33 道因原始 `lenient=false` 被直接跳过严格 judge（`judge=null`），因此 exact 缺口还有已知判分不确定性。按“来源覆盖 + partial”抽样核查答案遗漏、额外补充和关系错误，比盲目扩大召回更有信息量。

这 530 道只覆盖四个 ID 可对账的对话，并且历史召回 ID 的并集可能漏掉从未被任何题召回的记忆；绝不能外推为全 10 对话的提取漏失率或 Jev/图的收益上界。

## 四道“来源会话已到达”题的事实级复核

从上述 146 道里按单跳、多跳、时间、开放题各取一道机制不同的题。逐题对照中文原始 turn、相应记忆全文、最终 top-15、回答和严格判分；这是**定向案例**，不代表各类错误占比。

| 题目 | 具体证据流向 | 解释与边界 |
|---|---|---|
| **conv-26_qa85**：“卡罗琳夏天有什么计划？” | `D2:8` 明确说“我在研究收养机构”。这条事实被记成“卡罗琳正在研究收养机构”，在 top-15 的**第 12 位**；答题器却列出大会、艺术展、出游和游行，没有提收养。金标是“调研领养机构”，归档 wrong 因 `lenient=false` 没进严格 judge。 | 属于**证据在场但被更靠前的同主题计划压过**；可检验问句中“夏天”的时间范围、重排顺序和回答时的证据选择。不能归为提取缺失。原文该 turn 没有显式“夏天”，金标可能借助上下文指代，须保留这一歧义。 |
| **conv-26_qa36**：“什么时候加入导师辅导项目？” | `D9:2` 于 **2023-07-17** 说“上周末我参加了”，正确相对日期是 **7 月 15–16 日**。top-15 第 1 条同 session 记忆把它写成 **7 月 8–9 日**；回答照抄该错误日期，被严格 judge 判 wrong。 | 是**写入时的相对日期归一化错误**，而非检索不到。需要保存原句和会话日期、对日期运算做确定性校验；图加宽和 Jev 停止准则均不会自动修正错误的高排位记忆。 |
| **conv-30_qa31**：“乔恩花多久开起工作室？” | `D1:2` 于 2023-01-20 称“昨天丢工作”并计划创业，`D15:13` 于 2023-06-19 称“明天盛大开幕”。从 **1 月 19 日到 6 月 20 日是 152 天，约 5 个月**。top-15 同时有这两端日期，回答“约 5 个月”；中英文金标均写“六个月”，严格 judge 判 wrong。 | **金标/时间口径冲突的疑点**：若按跨越的日历月份数可口语化说“六个月”，按实际历时是约 5 个月。此题不能作为模型算错时长的确凿证据，建议评测中同时接受有依据的日期推导，或单列争议题。另有 session_5 记忆称 2 月已开办、后续却仍筹备 6 月正式开幕，需区分“开始经营”和“正式开幕”。 |
| **conv-43_qa15**：“安东尼是谁？” | 唯一金标 `D4:8` 只说“我和安东尼去参加一个慈善活动”，没有明确关系。top-15 第 1 条忠实记录同行活动。回答“约翰的朋友/同伴”并补了活动细节；中英文金标均是“可能是朋友、同事或家人”，严格 judge 因只选一种可能而判 partial。 | **源证据不足以唯一确定关系**；答案的“朋友”推测与金标允许的备选之一兼容，但表达确定性过强。这属于不确定性表达/判分口径问题，不能解释成图没找到身份事实。 |

这四例支持更细的投资顺序：先校准源日期与记忆日期、标出有争议的时间金标，再评估证据已在场时的选择与回答；只有确认事实真的在池里但没入 top-15 的题，才优先尝试图桥接或 Jev 扩拉。

## 对下一步的具体影响

1. 中文纯净基线的错误样本须有逐题漏斗字段：source turn、full pool、候选池、top-15、答案、判分，人工复核者能点开原文。
2. 原子提取 POC 先看低频实体和跨 turn 关系，检查是否救回 conv-30_qa37 一类；只看事实数量会掩盖“主题曲属于哪部电影”的关系丢失。
3. 图 POC 应专门盯 conv-43_qa21 一类“池中有但没召回”的多实体问题，同时保护已经排进 top-15 的金标事实，记录挤出损失。
4. 答案和判分 POC 处理 conv-26_qa43 / conv-43_qa2 一类“证据在场仍失分”，不要把它们归为图失败；开放推理题单独评估多种合理答案。

本批分析零模型调用；8 道对抗题严格复核的调用另记在 `adversarial_gate_poc_report_zh.md`。
