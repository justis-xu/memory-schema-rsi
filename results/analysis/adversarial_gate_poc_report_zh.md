# 中文对抗题预筛门 POC：`wrong` 不能直接读作“编造”

时间：2026-09-26。数据：中文首轮 `results/precision_regrade_zhfull.jsonl`，逐题复核 `adversarial_gate_poc_20260926.json`。调用：glm-5.3 **8 道固定题，每题成功一次**；未重答、未改原判分文件，缓存另存 `adversarial_gate_poc_cache.json`。

## 为什么做

`scripts/regrade_precision.py` 默认只把宽松判对的答案送严格判分；宽松判错直接 `final=wrong`，`judge=null`。中文首轮 444 道 adversarial 中，原报告把 373 道 `wrong` 解释为“编造”。但这 373 道里 **254 道没有严格判分**，只能说“宽松判错，被默认映射为 wrong”。其中至少 67 道答案含有“没有记录／无法确定／未提到”等拒答信号；这个词面筛选既不完整，也不能证明答案合格。

## 固定样本与结果

开始复判前固定 8 个 `case_id`：覆盖干净拒答、纠正错误主体、拒答后附带相关信息、拒答后仍给出猜测。它是**有意覆盖边界的样本**，不是随机抽样，不能推算 254 道的真实比例。

| 题目 | 原记录 | 新严格判分 | 复核要点 |
|---|---|---|---|
| conv-26_qa179 | wrong，无严格判分 | **exact** | 明确说没有奥斯卡藏骨头的记录；额外信息未当作答案 |
| conv-30_qa103 | wrong，无严格判分 | partial | 拒答并纠正主体，判分器认为额外细节可能是猜测 |
| conv-41_qa169 | wrong，无严格判分 | **exact** | 说明加入教堂的是玛丽亚，不是约翰 |
| conv-42_qa222 | wrong，无严格判分 | **exact** | 直接说没有游戏聚会及人数记录 |
| conv-43_qa182 | wrong，无严格判分 | partial | 指出蒂姆无比赛得分，另提约翰 40 分；判分器认为附加事实不当 |
| conv-44_qa134 | wrong，无严格判分 | **exact** | 指出“马克斯”是奥黛丽童年的狗，不是安德鲁的 |
| conv-47_qa171 | wrong，无严格判分 | wrong | 虽说没有舞蹈课记录，最后仍答“10 美元”——确实给了无依据的答案 |
| conv-49_qa190 | wrong，无严格判分 | **exact** | 明确说饮食限量未被提及 |

新判分汇总：**5 exact、2 partial、1 wrong**。这是对“`wrong` 全等于实际编造”的直接反例，也是对严格复核流程的验证。它不能说明总体真实编造率是多少。

## 还需谨慎的地方

严格判分器只看题目、gold 和答案，看不到源对话；它把某些“纠正错误主体”的附加细节称为“虚构”，并未验证那些细节在源对话中是否存在。因此这里区分三件事：

1. **J 指标用的干净拒答**：是否明确拒答且没有作为答案给出猜测；
2. **回答是否有错误主体纠正或额外细节**：可能有用，也可能多余；
3. **事实是否编造**：必须回查原始 source turn 或可信记忆，不能仅从 `final=wrong` 推断。

原报告的 45/444 “干净拒答”和 373/444 “编造”都应标成**预筛门后的归档分级**。目前只证明其中至少 5 道原 wrong 能被同一严格判分器重判为 exact；不重估总体比率，也不从该样本外推。若要出可信对抗题指标，先对所有宽松判错题用 `judge-all` 或分层抽样复判，随后人工核对“额外细节是否有源证据”。

此 POC 没有改变中文记忆、图、Jev 或主评测结果；它修正的是**如何解释这些结果**。下一轮若要改答题 prompt，应把“干净弃权率”和“有源证据的纠错说明”分开报告。
