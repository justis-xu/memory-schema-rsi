# 中文融合图臂：候选进入、挤出与翻分账

2026-09-26。复算脚本 `scripts/audit_graph_context_zh.py`，逐题机器结果 `graph_context_audit_20260926.json`。配对 2026-09-25 16:46 的中文无图臂与 17:21 的融合图臂，共同的 **1,540 道 J 类**，使用各自严格重判。`graph_context_ids` 在这组**无 Jev**归档中与最终上下文一致；Jev 扩拉归档的同名字段会过期，不适用本脚本。

## 图在 15 个槽位中实际做了什么

| 入选情况 | 题数 | 图臂独得 / 无图独得 | 净 exact | 两臂完整上下文相同 |
|---|---:|---:|---:|---:|
| 没有图候选入选 | 506 | 32 / 29 | +3 | 482 |
| 至少一个图入选 ID 不在无图候选中 | 1,025 | 60 / 47 | +13 | 0 |
| 图入选 ID 在无图候选中出现过 | 9 | 1 / 0 | +1 | 0 |
| **合计** | **1,540** | **93 / 76** | **+17** | **482** |

图候选在 **1,034/1,540** 道题进入最终上下文，共 **2,042 次记忆入选**；其中 2,024 次的 ID 不在同题无图臂的 15 条检索结果中，18 次在无图检索里已有。同一条记忆可在多道题重复计数。这里的“新”仅指**本题这次无图候选集合没有该 ID**，不是新生成的事实，也不意味着基线系统永远检索不到它。图臂的图候选在本臂向量候选之外，这是代码的 `exclude_ids` 规则。

相对无图答题上下文，图臂总计挤出 **2,084 次原有记忆 ID**。该数与 2,042 次图入选不必相等：跨两次运行的向量检索/重排也可能变化；没有图候选入选的 506 道里仍有 24 道 ID 上下文不同。图候选入选记录 **0/2,042** 带 `session_date`，与图路径丢日期的代码分析一致。日期可能写在记忆正文，但答题器读取的日期元数据没有了。

同一归档的其他题向量召回记录中，**2,034/2,042 次图入选**能按相同 ID 找到内容完全一致、且含 `session_date` 的原记忆；余下 8 次只涉及 2 个不同 ID，当前归档里无同 ID 向量记录可核。这证明日期字段通常不是源中不存在，而是图候选转成答题 `MemoryRecord` 时没有带过去。它也给出一个非常小的实现验证点：按原始 ID 继承日期，不改变候选选择。

配置里的 `graph_slots: 3` 注释明确只管 **bypass** 模式。融合模式把候选统一重排进 15 槽，**没有 3 条图记忆的硬上限**：本次 115/1,540 题选入 4–7 条图记忆（71 题为 4 条、28 题为 5 条、12 题为 6 条、4 题为 7 条），这些题合计 524 次图入选。不是代码违背该配置，而是融合设计没有保护直接向量证据槽位；后续要测试保留槽位必须显式新增约束，并记录它是否挤掉了真正相关的图证据。

最能限制因果解读的是 **482** 道两臂有完全相同的有序 ID、内容和日期的题：其中仍有 **59 道**严格 exact 状态翻转。没选到图的整组是 32 赢、29 输；选到本题无图候选以外 ID 的组是 60 赢、47 输。后者净 +13，但组别是**干预后结果**，且两次答题生成本身波动很大，不能将 +13 作为图记忆的因果收益。类似地，不能据 2,024 个新 ID 推断带来了 2,024 条新答案事实。

一个具体边界例是 `conv-44_qa58`：图臂选入 6 条图记忆，然而**两臂第 1 条都直接写着“奥黛丽当天打算晚饭点寿司”**，两次回答也都说寿司与“打算”。无图答案被严格 judge 判 exact，图答案被判 partial，理由是“只说计划而非实际吃了”。源证据本身也只说打算，此次翻分不能解释为图挤走“寿司”事实，反而暴露了答案确定性与严格判分边界的不一致。需要统一评价“计划”与“实际发生”的口径。

## 对下一轮实验的直接要求

1. 固定同一题的向量候选和顺序，再只开关图候选进入；记录图节点 `anchor_memory_id`、原始记忆 ID、日期、支持的源 turn 和被挤出的记忆。避免把两次独立向量检索变化算作图作用。
2. 先判断图候选是否**独有且可核的答案事实**，再看得分；若只是话题相关或已在原上下文的同义事实，不应占用 15 槽。
3. 对 date/temporal 题，图候选至少恢复原记忆的 `session_date`，再用固定上下文的小样本测日期答题；不能同时改图宽度、原子池、prompt。
4. 以同配置重复运行的翻转作为噪声参照。单次 +17/1,540 不足以确认稳定收益，尤其是没有图入选时也有 +3 净翻分。

本审计只复算归档，零模型调用；不修改图或评测管线。
